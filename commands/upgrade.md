description: Preview or apply instruction and memory upgrades for the active profile
---

Use `upgrade` when the repo contract or profile instructions need to be refreshed.

Core forms:

- `upgrade` applies the full sync pass to the target docs and memory layers
- `upgrade preview` inspects the target without writing files
- `upgrade status` shows the same preview in a status-style summary
- `upgrade docs` rewrites only the agent/profile docs
- `upgrade profile` rewrites the active profile doc and profile memory
- `upgrade memory` rewrites only the profile and host memory layers
- `upgrade hosts` rewrites only the host memory layers
