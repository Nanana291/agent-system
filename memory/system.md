# System Memory

Durable rules that apply to the whole repository live here.

## Usage

- Write a rule here when it is true across profiles and hosts.
- Prefer a profile memory file when the rule only applies to one profile.
- Prefer a host memory file when the rule only applies to one host.

## Initial durable rules

- Superpowers decides process.
- Agent System decides route, ownership, handoff, and delivery gates.
- Structured manifests are authoritative over human-facing docs when they differ.
