# Learning Packs

This directory holds compact host learning packs derived from the host memory files.

- `claude.md` summarizes Claude-specific durable lessons.
- `codex.md` summarizes Codex-specific durable lessons.
- `qwen.md` summarizes Qwen-specific durable lessons.

Use `memory packs generate --host <name>` to refresh a pack and `memory packs list --host <name>` to inspect its path.
